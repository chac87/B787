# Kabinenvorbereitung

Wenn absehbar ist, dass eine Notlandung/Notwasserung mit eventueller Evakuierung bevorsteht:
→ PA-Call **„Purser to Interphone!"**

## AZU-Briefing

| **A** | **Z** | **U** |
|:---|:---|:---|
| Art des Notfall | Zeit zur Kabinenvorbereitung | Umsetzen von Passagieren? |
| Risiken bei der Landung? | *NICHT die Zeit bis zur Landung!* | |
| Schutzhaltung ja/nein? | | |

> [!info]
> Der Purser entscheidet selbstständig, ob eine zeitkritische oder nicht-zeitkritische Vorbereitung durchgeführt wird.
