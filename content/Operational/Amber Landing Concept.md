# Amber Landing Concept

## Definitionen

| Kürzel | Begriff | Erläuterung |
|:---|:---|:---|
| **LDA** | Landing Distance Available | Verfügbare Landedistanz |
| **ALD** | Actual Landing Distance | Von Testpiloten auf trockener Bahn erflogen |
| **RLD** | Required Landing Distance | Referenzdistanz bei der Flugplanung, gut erreichbar für Piloten<br>RLD<sub>dry</sub> = ALD · 1,67<br>RLD<sub>wet</sub> = ALD · 1,92 |
| **ILD** | Inflight Landing Distance | Bildet die durchschnittliche Pilotenperformance inflight ab |
| **FLD** | Factored Landing Distance | FLD = ILD · 1,15<br>Grundlage zur Planung von LAPA |


## Konzept

- Puffer zur Landung = LDA − FLD<sub>Manual Braking</sub>
- Vom Überfliegen der Schwelle bis zum Aufsetzen vergehen ca. **5 sec**
- Das entspricht in Realität etwa **500 m** hinter der Schwelle (gewollt: 300 m)
- Da die Standard-TDZ **900 m** lang ist, kann bei einem Puffer > 400 m die volle TDZ genutzt werden
- → Bei einem Puffer **≤ 400 m** (LAPA FLD<sub>Manual</sub> = amber) gilt das **Amber Landing Concept**
- Go-Around Point = **500 m + (LDA − FLD)**
- Der GA-Point sollte im Briefing anhand markanter Punkte in der Karte definiert werden

> [!warning] LDA < 2.400 m
> TDZ ist nur **600 m** lang.
