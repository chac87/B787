# Dual Eng Fail-Stall

<a class="nnc-back" href="/Non-Normals/Non-Normal-Checklists">Non-Normal Checklists</a>

<div class="nnc-condition">Condition: Engine speed for both engines is below idle.</div>

<div class="nnc-item"><span class="nnc-num">1</span><strong>FUEL CONTROL switches (both)</strong><span class="cl-dots"></span><strong>CUTOFF, then RUN</strong></div>
<div class="nnc-item"><span class="nnc-num">2</span><strong>RAM AIR TURBINE switch</strong><span class="cl-dots"></span><strong>Push and hold for 1 second</strong></div>

<div class="nnc-separator"></div>

<div class="cl-variant">B787 (-ABPF to -ABPU)</div>

<div class="nnc-text"><span class="nnc-num">3</span>Set airspeed above 250 knots.</div>
<div class="nnc-item"><span class="nnc-num">4</span><strong>APU selector (if APU available)</strong><span class="cl-dots"></span><strong>START, then ON</strong></div>
<div class="nnc-text"><span class="nnc-num">5</span><strong>If</strong> volcanic ash is suspected:</div>
<div class="nnc-goto">▶▶&ensp;Go to the Volcanic Ash checklist, if not already done, and return to this checklist when directed.</div>
<div class="nnc-text"><span class="nnc-num">6</span>The engines can accelerate to idle very slowly, especially at high altitudes.</div>
<div class="nnc-text"><span class="nnc-num">7</span>Do not interrupt the start attempts. Move the fuel control switch to CUTOFF only when no further start attempts are needed.</div>
<div class="nnc-text"><span class="nnc-num">8</span><strong>When</strong> one engine is running:</div>
<div class="nnc-item"><span class="nnc-num">9</span><strong>STAB cutout switches (both)</strong><span class="cl-dots"></span><strong>NORM</strong></div>
<div class="nnc-sub">The STABILIZER message can show. The stabilizer functions normally when power is restored.</div>
<div class="nnc-note"><strong>Note:</strong> The right center fuel pump is inoperative for the rest of the flight.</div>
<div class="nnc-text"><span class="nnc-num">10</span>Do <strong>not</strong> accomplish the following checklist:</div>
<div class="nnc-sub">• STABILIZER</div>

<div class="cl-variant-end">END B787 (-ABPF to -ABPU)</div>

<br>

<div class="cl-variant">B787 (-ABPA to -ABPE)</div>

<div class="nnc-text"><span class="nnc-num">3</span>Set airspeed above 270 knots.</div>
<div class="nnc-item"><span class="nnc-num">4</span><strong>APU selector (if APU available)</strong><span class="cl-dots"></span><strong>START, then ON</strong></div>
<div class="nnc-text"><span class="nnc-num">5</span><strong>If</strong> volcanic ash is suspected:</div>
<div class="nnc-goto">▶▶&ensp;Go to the Volcanic Ash checklist, if not already done, and return to this checklist when directed.</div>
<div class="nnc-text"><span class="nnc-num">6</span>The engines can accelerate to idle very slowly, especially at high altitudes. The time from fuel control switch to RUN to stable idle can take up to two and a half minutes.</div>
<div class="nnc-text"><span class="nnc-num">7</span>Do not interrupt the start attempts. Move the fuel control switch to CUTOFF only when no further start attempts are needed.</div>
<div class="nnc-text"><span class="nnc-num">8</span><strong>When</strong> one engine is running:</div>
<div class="nnc-item"><span class="nnc-num">9</span><strong>STAB cutout switches (both)</strong><span class="cl-dots"></span><strong>NORM</strong></div>
<div class="nnc-sub">The STABILIZER message can show. The stabilizer functions normally when power is restored.</div>
<div class="nnc-note"><strong>Note:</strong> The right center fuel pump is inoperative for the rest of the flight.</div>
<div class="nnc-text"><span class="nnc-num">10</span>Do <strong>not</strong> accomplish the following checklist:</div>
<div class="nnc-sub">• STABILIZER</div>

<div class="cl-variant-end">END B787 (-ABPA to -ABPE)</div>
