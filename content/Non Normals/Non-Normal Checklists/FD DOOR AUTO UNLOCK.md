# [] FD DOOR AUTO UNLOCK

<a class="nnc-back" href="/Non-Normals/Non-Normal-Checklists">Non-Normal Checklists</a>

<div class="nnc-condition">Condition: The correct emergency access code is entered.</div>

> [!info]- Procedure
> If access is not to be permitted, the FD DOOR ACCESS selector is moved to DENY and held for 1 sec. This must be done during the 30 sec delay period. Select DENY.
>
> Any subsequent keypad access requests are automatically denied for 30 min. The door may be manually opened at any time from the flight deck by turning the door handle.
