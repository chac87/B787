# <span class="h1-bracket">[]</span> ENG EEC MODE L, R

<a class="nnc-back" href="/Non-Normals/Non-Normal-Checklists">Non-Normal Checklists</a>

<div class="nnc-condition">Condition: An EEC is in the alternate control mode.<br>Objective: To run both engines in the alternate mode.</div>

<div class="nnc-item"><span class="nnc-num">1</span><strong>Autothrottle disconnect switch</strong><span class="cl-dots"></span><strong>Push</strong></div>

<div class="nnc-item"><span class="nnc-num">2</span><strong>Thrust levers (both)</strong><span class="cl-dots"></span><strong>Retard to mid position</strong></div>
<div class="nnc-sub">This prevents exceeding the thrust limits when switching to the alternate mode.</div>

<div class="nnc-box">Push one switch at a time.</div>

<div class="nnc-item"><span class="nnc-num">3</span>⚠ <strong>EEC MODE switches (both)</strong><span class="cl-dots"></span><strong>Off</strong></div>

<div class="nnc-text"><span class="nnc-num">4</span>Engage the autothrottle.</div>
<div class="nnc-note"><strong>Note:</strong> Maximum thrust limiting is not available with autothrottle disconnected. Alternate thrust setting information shows on the N1 indications.</div>

<div class="nnc-text"><span class="nnc-num">5</span>Do <strong>not</strong> accomplish the following checklist:</div>
<div class="nnc-sub">• ENG EEC MODE (for other engine)</div>
