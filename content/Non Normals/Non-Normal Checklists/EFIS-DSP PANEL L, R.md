# <span class="h1-bracket">[]</span> EFIS-DSP PANEL L, R

<a class="nnc-back" href="/Non-Normals/Non-Normal-Checklists">Non-Normal Checklists</a>

<div class="nnc-condition">Condition: One of these occurs:<br>• The EFIS/DSP panel is failed<br>• MFD control of the EFIS/DSP is used</div>

<div class="nnc-note"><strong>Note:</strong> Backup control of the affected EFIS/DSP panel is accessed from the MFD system display, using the EFIS/DSP select key. The EFIS/DSP BACKUP page can be shown and controlled on any operable MFD.</div>

<div class="nnc-text"><span class="nnc-num">1</span>Select SYS on the MFD.</div>

<div class="nnc-text"><span class="nnc-num">2</span>Select EFIS/DSP.</div>

<div class="nnc-text"><span class="nnc-num">3</span>Select CAPT or F/O.</div>

<div class="nnc-text"><span class="nnc-num">4</span>Select EFIS CTRL BACKUP.</div>

<div class="nnc-text"><span class="nnc-num">5</span>Use backup control as needed.</div>
