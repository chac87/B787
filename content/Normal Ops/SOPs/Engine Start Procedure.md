# Engine Start Procedure

<div class="checklist">

<div class="cl-item"><strong>"ENGINE START"</strong><span class="cl-dots"></span><strong>Announce — C</strong></div>
<div class="cl-sub">Select the secondary engine indications. — F/O</div>
<div class="cl-sub">Crew action to correct for abnormal engine indications is not needed. Respond to any EICAS messages that show.</div>
<div class="cl-note">The engines may not start if external power and the APU are both supplying electric power at the same time. One source must be selected off. The APU is the preferred electric power source for engine start.</div>
<div class="cl-note">Do not make flap or primary flight control inputs on the ground until after the EICAS engine RUNNING indication appears and all four GEN CTRL OFF lights are extinguished. The electric spoilers are susceptible to nuisance failures if commanded to move during electrical power transfers.</div>
<div class="cl-caution">If OAT is above 40°C, do not attempt to start both engines at the same time.</div>

<div class="cl-item"><strong>Start sequence</strong><span class="cl-dots"></span><strong>Announce — C</strong></div>
<div class="cl-sub">The engines may be started at the same time.</div>
<div class="cl-sub">Call "START ___ ENGINE" — C</div>
<div class="cl-item cl-indent"><strong>Engine START selector</strong><span class="cl-dots"></span><strong>START — F/O</strong></div>
<div class="cl-item cl-indent"><strong>FUEL CONTROL switch</strong><span class="cl-dots"></span><strong>RUN — C</strong></div>
<div class="cl-sub">If the engines were not started at the same time:</div>
<div class="cl-sub cl-indent">After the engine is stabilized at idle, start the other engine.</div>

</div>
