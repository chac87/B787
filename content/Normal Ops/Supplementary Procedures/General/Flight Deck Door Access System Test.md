# Flight Deck Door Access System Test


<div class="checklist">

<div class="cl-item"><strong>Flight deck door</strong><span class="cl-dots"></span><strong>Open</strong></div>

<div class="cl-item"><strong>FD DOOR ACCESS selector</strong><span class="cl-dots"></span><strong>AUTO</strong></div>

<div class="cl-item"><strong>FD DOOR POWER switch</strong><span class="cl-dots"></span><strong>OFF</strong></div>
<div class="cl-sub">At least 20 seconds after the switch is selected to OFF, verify FD DOOR LOCK FAIL EICAS advisory message shows.</div>

<div class="cl-item"><strong>FD DOOR POWER switch</strong><span class="cl-dots"></span><strong>ON</strong></div>
<div class="cl-sub">Verify FD DOOR LOCK FAIL EICAS advisory message blanks.</div>

<div class="cl-item"><strong>Emergency access code</strong><span class="cl-dots"></span><strong>Enter</strong></div>

<div class="cl-item"><strong>ENT key</strong><span class="cl-dots"></span><strong>Push</strong></div>
<div class="cl-sub">Verify FD DOOR AUTO UNLOCK EICAS warning message shows, master WARNING lights are on, and aural alert sounds.</div>

<div class="cl-item"><strong>FD DOOR ACCESS selector</strong><span class="cl-dots"></span><strong>DENY</strong></div>
<div class="cl-sub">Verify FD DOOR AUTO UNLOCK EICAS warning message blanks.</div>

<div class="cl-item"><strong>FD DOOR ACCESS selector</strong><span class="cl-dots"></span><strong>UNLKD</strong></div>

</div>
