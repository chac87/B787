# RWY Change For Dep

This procedure should preferably be performed with aircraft stationary and parking brake set.

A sole change of SID without change in runway and/or intersection can be done without applying this procedure.

<div class="checklist">

<div class="cl-item"><strong>ROUTE (RWY, SID, TRANS)</strong><span class="cl-dots"></span><strong>CHECK/MODIFY</strong><span class="mi-role mi-role--pm">F/O</span></div>
<div class="cl-sub">Modify/confirm FMS setup according to new ATC clearance.</div>

<div class="cl-item"><strong>TAKEOFF PERF DATA</strong><span class="cl-dots"></span><strong>RECOMPUTE</strong><span class="mi-role mi-role--both">BOTH</span></div>
<div class="cl-sub">Both crewmember independently re-compute the takeoff performance data.</div>

<div class="cl-item"><strong>FMS TAKEOFF DATA</strong><span class="cl-dots"></span><strong>REVISE</strong><span class="mi-role mi-role--pm">F/O</span></div>
<div class="cl-sub">The F/O revises the performance data in the FMS (THR LIM &amp; T.O. REF page 1&amp;2)</div>

<div class="cl-item"><strong>FMS REVISED TAKEOFF PERF DATA</strong><span class="cl-dots"></span><strong>CROSSCHECK</strong><span class="mi-role">CP</span></div>
<div class="cl-sub">The C crosschecks the performance data displayed on his EFB with the FMS data on THR LIM, T.O.REF page 1&amp;2 and N1 Limit on EICAS display.</div>

<div class="cl-item"><strong>FLAPS LEVER</strong><span class="cl-dots"></span><strong>AS APPROPRIATE</strong><span class="mi-role mi-role--pm">F/O</span></div>
<div class="cl-sub">Check or select takeoff position.</div>

<div class="cl-item"><strong>MCP</strong><span class="cl-dots"></span><strong>SET</strong><span class="mi-role">CP</span></div>
<div class="cl-sub">C sets v<sub>2</sub>, LNAV, VNAV, HDG/TRK, ALT as required.</div>

<div class="cl-item"><strong>TRIM</strong><span class="cl-dots"></span><strong>CHECK/SET</strong><span class="mi-role">CP</span></div>
<div class="cl-sub">Check or re-set stabilizer takeoff trim.</div>

<div class="cl-item"><strong>LEGS PAGE (SPEED AND ALT CSTR)</strong><span class="cl-dots"></span><strong>CHECK</strong><span class="mi-role mi-role--both">BOTH</span></div>

<div class="cl-item"><strong>DEPARTURE BRIEFING</strong><span class="cl-dots"></span><strong>COMPLETE</strong><span class="mi-role mi-role--both">BOTH</span></div>

<div style="text-align:center; margin: 0.8em 0;"><span class="sop-tag-cl">CP → F/O: "RWY CHANGE FOR DEPARTURE CHECKLIST"</span></div>

</div>

- If the "Before Takeoff Checklist" had been completed prior to performing this procedure it has to be read again.
