# Ground Power Engine Start

This procedure assumes the APU is not available for engine start. Engine starts from ground power require the forward left and right external power sources to be providing power. The aft external power source may also be used, if available. This reduces electrical load shedding during the start of the right engine.

> [!info] Note
> During ground power starts, expect significant equipment reconfigurations and electrical load shedding while the first engine is starting. This includes F/O displays, EFB, right CCR, MCP, and numerous cabin loads. Audio control panel receive and transmit selections may be lost. Reselect if needed after the first engine is running.

If three external power sources are used, start the right engine first to reduce load shedding.

> [!info] Note
> Attempting ground power start with cabin temperatures above 46° C may be unsuccessful due to PECS overheat during start.

<div class="checklist">

<div class="cl-item"><strong>External power sources</strong><span class="cl-dots"></span><strong>Connect</strong></div>
<div class="cl-sub">Select FWD EXT PWR L and FWD EXT PWR R switches ON. Select AFT EXT PWR switch ON, if available.</div>

</div>

> [!info] Note
> Advise the cabin to expect the loss of some cabin functions during engine start.

Start the first engine.

**After** the first engine start is complete:

<div class="checklist">

<div class="cl-item"><strong>External power sources</strong><span class="cl-dots"></span><strong>Disconnect</strong></div>
<div class="cl-sub">Verify that all external power AVAIL lights are illuminated. Disconnect external power sources.</div>

</div>

<div class="cl-variant">B787 (-ABPA to -ABPE)</div>

Use cross start procedures to start the remaining engine.

<div class="cl-variant-end">END B787 (-ABPA to -ABPE)</div>

<div class="cl-variant">B787 (-ABPF to -ABPU, -ABQA to -ABQG)</div>

Use normal procedures to start the remaining engine.

<div class="cl-variant-end">END B787 (-ABPF to -ABPU, -ABQA to -ABQG)</div>
