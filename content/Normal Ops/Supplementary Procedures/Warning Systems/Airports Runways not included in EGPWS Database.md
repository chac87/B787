# Airports/Runways not included in EGPWS Database

> [!info] Note
> Airports / runways not included in the EGPWS database are published by ILOS COC. For valid database check HIL.

For operations to/from a runway not included in the EGPWS database the enhanced function must be inhibited but only when the airplane is less than 15 NM from that runway. That is to avoid false terrain alerts.

> [!info] Note
> The EGPWS internal database consists of four sub-sets, a worldwide terrain database, an obstacle database containing cataloged obstacles 100 ft or greater, a worldwide airport database containing information on runways 3500 ft or longer in length and an Envelope Modulation database.
