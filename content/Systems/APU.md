# APU

- 2 APU Starter Generators ASG
- Can be started up to 43.1000 ft
- Generator output decreases with altitude
- Attended Mode: Eng Start, In Flight
- Unattended Mode: Ground Movement, Parking
## APU Start
- Start on Main Battery or APU Battery
- APU starter cutout at 50 %
- APU can start without any pump (via suction feed)
- after 2 start attempts -> 5 min cooling time
- ≥ 3 GENs fail -> APU Auto Start
## APU Shutdown
- 2 min cooldown time
- APU door closes at 15 % N1
